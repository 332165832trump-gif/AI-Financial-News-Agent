# 09 - 下一步怎么走

## 你已经能做什么

从完全不懂 API，到能独立构建一个 **8 阶段的 AI Agent**，你已经掌握了：

1. ✅ 从互联网获取数据（NewsAPI, yfinance）
2. ✅ 调用大语言模型（DeepSeek via OpenAI SDK）
3. ✅ 结构化输出（JSON Schema + 容错解析）
4. ✅ 自动化定时运行（while True + time.sleep）
5. ✅ 数据持久化（JSON 文件读写）
6. ✅ 数据注入（把行情数据放进 Prompt）
7. ✅ Agent 设计（Observe→Think→Decide→Act）
8. ✅ 质量评估（人工审核 + 正确率统计）

## 短期可以扩展的方向

### 1. 通知系统

把日报发送到邮箱或微信。需要学 `smtplib`（发邮件）或 `requests` 调 Webhook。

### 2. 更多数据源

用你学过的 Playwright 爬更多新闻网站（新浪财经、东方财富、财联社）。

### 3. 历史数据查询

写一个脚本搜索历史日报：过去一周哪些新闻提到了 Nvidia？

### 4. 可视化图表

用 matplotlib 画每日情绪走势图、资产关注热度图。

### 5. 回测系统

验证 AI 的判断有多准：某天 AI 说 NVDA 偏空，一周后看实际涨跌。

## 保持以终为始的学习方式

不要按 语法 → 语法 → 语法 的方式学，而是：

1. 定一个小目标（例如把日报发到邮箱）
2. 只学实现这个目标需要的知识
3. 写出来，跑通，理解
4. 再定下一个目标

你今天已经证明了这种方式有效——从 0 到 Agent。
